The client's own wallet: ERG and token balances, block rewards, and the list of verified tokens those balances are matched against. Balances and rewards require an `api_key`; the verified list does not.

**All amounts are decimal strings, not JSON numbers.** ERG amounts are nanoERG; LIT amounts are base units (9 decimals).
